# Rustias AU / VST3

[English](README.md)

Полная версия Rustias без прошивки в виде плагина для DAW. **Генерация звука,
фильтры, голоса, сэмплер и эффекты заранее компилируются из Rust в машинный код**
для Apple Silicon, Intel macOS, Windows x64 и Linux x86_64. В звуковом движке плагина нет
WASM-рантайма.

Браузер и плагины собирают одни исходники Rust: восемь тембров, 128 голосов,
OSC 3/4, модульные соединения и цепочки эффектов. Модуляционные секвенсоры и
автоматизация макросов тоже исполняются нативно на Rust. Редактор использует
общий браузерный интерфейс. Исходный desktop-профиль
для эталонных сравнений сохраняется.

## Установка

Установщики и контрольные суммы доступны в [GitHub Releases](https://github.com/fushugaku/Rustias/releases/latest).

**macOS 12+, Apple Silicon и Intel:** откройте `Rustias-macOS-<версия>.pkg`.
В установщике можно выбрать AU, VST3 и CLAP. Плагины установятся для вашей
учётной записи в `~/Library/Audio/Plug-Ins/`, пароль администратора не нужен.
Старые версии атомарно заменяются вместе с ресурсами. Перед установкой закройте
DAW, затем откройте её заново и обновите список плагинов.

ZIP также доступен: распакуйте `Rustias-macOS-AU-VST3.zip` и запустите
`Install.command`. Можно установить вручную: `Rustias.component`
в `~/Library/Audio/Plug-Ins/Components/`, `Rustias.vst3` в
`~/Library/Audio/Plug-Ins/VST3/`. AU — инструмент для Logic и GarageBand,
VST3 — для Ableton Live, Cubase, REAPER и других совместимых DAW.
Перезапустите DAW и пересканируйте плагины. Локальные сборки подписаны ad-hoc;
PKG не подписан, если не настроен сертификат установщика. Нотариализации
Apple Developer ID пока нет.

**Windows 10/11 x64:** запустите `Rustias-Windows-x64-<версия>-Setup.exe` и выберите VST3 и/или CLAP. Установка идёт в стандартные папки Common Files; есть удаление через Windows. Включены Visual C++ Runtime и загрузчик WebView2. Если WebView2 отсутствует, для его установки нужен интернет. Удаление плагинов сохраняет пользовательские библиотеки и записи в LocalAppData. EXE не подписан сертификатом Authenticode.

Для ручной установки распакуйте `Rustias-Windows-VST3.zip` и скопируйте
папку `Rustias.vst3` целиком в `C:\Program Files\Common Files\VST3\`.
Содержимое `Contents/Resources` необходимо для работы плагина.
Для редактора нужен [Microsoft WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).
Если DAW ещё не установила [Microsoft Visual C++ x64 Runtime](https://aka.ms/vs/17/release/vc_redist.x64.exe), установите его отдельно.
Звук работает и при закрытом редакторе.

В архивы также включён CLAP. На Mac его можно положить в
`~/Library/Audio/Plug-Ins/CLAP/`; на Windows `Rustias.clap` и
`Rustias.resources` должны лежать рядом в папке CLAP. Старый VST2 не собирается.

**Linux x86_64, X11/XWayland:** запустите `bash Rustias-Linux-x86_64-<версия>.run`. Плагины установятся в `~/.vst3` и `~/.clap`. Нужны Python 3 и WebKitGTK 4.1 версии 2.40+. В Debian/Ubuntu можно установить системный пакет с зависимостями: `sudo apt install ./Rustias-Linux-amd64-<версия>.deb`. Редактор работает отдельным процессом WebKitGTK и встраивается через X11/XWayland, поэтому версия GTK внутри DAW с ним не конфликтует. Пакеты для других архитектур пока не собираются.

Установщик `.run` сохраняет предыдущие плагины в `~/.local/state/rustias/plugin-backups`; для удаления запустите его с `--uninstall`. Библиотеки и записи сохраняются. DEB удаляется через пакетный менеджер.

## Работа в DAW

Добавьте инструментальную дорожку, загрузите Rustias и отправьте MIDI.
Статус **DAW** означает, что звук идёт в дорожку хоста; отдельное аудиоустройство
плагин не открывает. Каждый тембр принимает MIDI согласно своим настройкам
канала. Ноты задаются в DAW: внутреннего нотного секвенсора и кнопки Play
в плагине нет. Вкладки **Sound** и **Mod sequencer** занимают всю рабочую область
редактора. Уголок справа внизу позволяет растянуть окно через DAW.
Вкладка **Mod sequencer** содержит до шести независимых линий
на каждый тембр: 1–128 шагов, собственные деления, Step/Slide, направления,
Loop/OneShot и Key Sync. Доступна модуляция синтеза, сэмплов, эффектов,
модулей и макросов. Темп, Play/Stop и позиция DAW синхронизируют нативные
часы Rust; перемотка и переход через границу цикла задают соответствующую
позицию модуляции. Входящие MIDI-ноты тоже запускают модуляцию, в том числе
при остановленном транспорте.
Все MIDI-события сохраняют временные метки хоста. Обновления показаний ручек
объединяются с частотой до 30 Гц: поток CC и Pitch Bend больше не собирает
полную программу для каждого события в аудиопотоке.
Движение ручки синта передаёт одно значение. Rust обновляет базу модуляции
без пересборки секвенсоров и сброса их часов. Настройки секвенсоров, привязок
и используемых эффектов или модулей синхронизируются при их изменении.
Сохранение программ и тембров,
импорт RDL, загрузка сэмплов, записи и экспорт WAV/MP3 доступны в редакторе.

В автоматизацию DAW вынесены **Macro 1–8** и **Output level**.
Правый клик по ручке синтеза или эффекта позволяет привязать её к макросу;
карандаш у макроса открывает силу влияния и удаление привязок.

Проект DAW сохраняет текущую программу целиком: все тембры, мод-секвенсоры,
модуляции, макросы, соединения, эффекты и загруженные PCM-сэмплы.
Экземпляры плагина независимы. Библиотека пользовательских патчей и записи
хранятся локально в редакторе. Записи не входят в проект DAW;
для переноса экспортируйте их в WAV/MP3.
Нотные паттерны браузерных программ сохраняются для обратного переноса,
но в плагине не воспроизводятся. Цель Sequencer Gate недоступна:
длительность MIDI-нот задаёт DAW.

## Сборка и проверка

На Mac нужны Xcode Command Line Tools, Python 3, CMake 3.25+, Node 22+, Rust
и цели `aarch64-apple-darwin`, `x86_64-apple-darwin`, `wasm32-unknown-unknown`.
WASM нужен для ресурсов интерфейса и импорта RDL; DSP плагина собирается нативно:

```sh
bash scripts/build-plugin.sh
```

На Windows дополнительно нужны Visual Studio 2022 C++ Desktop Build Tools:

```powershell
./scripts/build-plugin-windows.ps1
```

На Linux нужны development-пакеты WebKitGTK 4.1, GTK3 и X11. Соберите те же CMake targets, запустите CTest под X11 (в CI используется Xvfb), затем `python3 scripts/package-plugin-linux.py`.

Архивы и установщики появятся в `output/plugin/packages/`. Workflow `plugins.yml` проверяет macOS universal, Windows x64 и Linux x86_64 при изменении общего движка или интерфейса. После push версии в `main` тег `v<версия>` публикует проверенные CI-артефакты этого же коммита с SHA-256 через `release.yml`, без повторной сборки других бинарных файлов. Версии SDK закреплены в CMake.

Готовые проверенные плагины Mac можно упаковать без повторной сборки звука:

```sh
python3 scripts/package-plugin-pkg.py --bundles output/plugin/packages/Rustias-macOS
```

Для подписи PKG задайте `RUSTIAS_INSTALLER_IDENTITY` — имя доступного сертификата
**Developer ID Installer**. Сборка проверяет распакованный payload, подписи,
архитектуры, установку в домашнюю папку, выбор форматов и замену старых версий.
Установщик содержит русский и английский тексты и не запускает install-скрипты.

Короткие буферы DAW рассчитывают только запрошенные сэмплы, без всплеска работы
на 128 сэмплов. Квант модуляции и контроллеров FX остаётся равным 128 сэмплам,
поэтому размер буфера не меняет звук. Аудиобуферы переиспользуются. Телеметрия
ограничена 20 обновлениями в секунду и отключается при закрытом или скрытом окне.

`ctest` сравнивает 125 сценариев PCM и состояния с реальной браузерной сборкой,
затем повторяет каждый с частичным рендерингом и требует побитового совпадения PCM.
Отдельная проверка сравнивает буферы 1/17/32/64/128/257/512 сэмплов при
44,1/48/96 кГц, события внутри блока, модуляцию и запись, а также одновременно
запускает четыре независимых экземпляра и сравнивает их с изолированным рендерингом.
Набор эталонов содержит 22 сценария модуляции напрямую через Rust ABI, без JavaScript-рантайма:
независимые часы, Step/Slide, направления, OneShot, Key Sync, биполярные макросы,
эффекты, цепочки, модули и профили сэмплов.
Также проверяются нативный движок на 44,1/48/96 кГц, MIDI, разные размеры буферов,
независимость экземпляров, сохранение состояния и смену частоты дискретизации.
Отдельный тест настоящего AU-редактора проверяет изменение размера окна,
выключение и включение аудио с открытым редактором, отсоединение и возврат
того же окна и многократное пересоздание редактора с сохранением автоматизации
и размера. Прямой хост проверяет скрытие и показ без повторного присоединения.
При упаковке Mac также запускается строгая проверка Apple `auval`.
Все звуковые проверки идут в память, без вывода звука. Цель
`rustias-plugin-preview` — отдельный тихий хост для проверки интерфейса,
который отбрасывает все выходные аудиобуферы.

CI также проверяет готовый модуль VST3 официальным валидатором Steinberg.
Отдельная проверка AU загружает его фабрику напрямую и проверяет MIDI,
стереозвук и сохранение автоматизации на 44,1/48 кГц. На CI она заменяет `auval`,
если системный реестр раннера не обнаруживает плагин. Локальная упаковка требует
строгой проверки `auval`. Прямую проверку можно запустить для обеих архитектур Mac.

## Устройство

Версия 0.2.5 копирует MIDI-состояние и телеметрию в заранее выделенные снимки.
JSON формируется фоновым потоком, который не читает работающий движок. При
переполнении обычного пула отдельный буфер сохраняет последнее MIDI/CC7 и полное
корректирующее состояние даже после Stop без следующего рендера. Модуляция FX
и цепочек вызывает общий компилятор напрямую. Рабочие списки изменений и связи
макросов/линий подготавливаются заранее. Запись переиспользует PCM-буферы, а
фоновые потоки ждут уведомлений вместо пробуждения каждые 2 мс.

Побитовое сравнение с замороженной 0.2.4 прошло для 210 сценариев адаптера и
12 сценариев плотной модуляции на Apple Silicon и Intel; снимки состояния тоже
совпали. Браузер сохранил PCM во всех 279 сценариях — 3 428 352 стереокадра.
Проверены восстановление ошибочных FX-параметров, повторяющиеся ID цепочек,
доставка после Stop при переполнении пула, телеметрия и каждый кадр записи.

Apple M5 Max, 48 кГц / 128 сэмплов, две серии ABBA; каждый запуск содержит
три повтора по 1 024 блока. Диапазоны показывают результаты отдельных запусков:

| Нагрузка | Среднее, мкс: 0.2.4 → 0.2.5 | P99, мкс: 0.2.4 → 0.2.5 |
| --- | ---: | ---: |
| Два AU параллельно, четыре источника / MS-20 / MIDI | 274–284 → 226–230 | 684–686 → 415–417 |
| Два нативных экземпляра, MIDI / телеметрия | 253–271 → 216–219 | 709–728 → 237–241 |
| Два нативных экземпляра, FX Slide / плотные макросы | 298–302 → 247–249 | 776 → 278–289 |
| Восемь нативных экземпляров, MIDI / телеметрия | 1 014–1 086 → 869–879 | 2 817–2 875 → 937–944 |

В тесте восьми экземпляров превышения бюджета 2 667 мкс снизились с 474 из
6 144 до 0 из 6 144. Тест runtime обрабатывает экземпляры последовательно с
телеметрией, без окон редактора; AU-тест включает синхронизацию параллельных
потоков. Для статичных двух/четырёх AU разница среднего времени — меньше 3%.
Это результаты конкретных офлайн-нагрузок, без гарантии планировщика DAW.
Число C++ `new` внутри измеренных MIDI/recording callbacks стало нулевым;
счётчик не включает выделения Rust, настройку и входящие JSON-команды редактора.

```sh
cmake --build output/plugin/build --target rustias-control-benchmark
output/plugin/build/rustias-control-benchmark output/plugin/resources result.json
```

Версия 0.2.4 убирает оставшийся интерпретатор из нативного аудиотракта.
В профиле работающего Logic у 0.2.3 обнаружены ожидания блокировок и сборщика
мусора JavaScriptCore в обоих потоках AU. Тихий стресс-тест на основе видимого
патча запускает два AU параллельно: по шесть голосов, четыре источника, два
фильтра MS-20 и непрерывные MIDI Wheel/Pitch с временными отметками. На Apple
M5 Max, 48 кГц и буфере 128 сэмплов, три повтора по 512 обработок дали:

| Замер | 0.2.3 | 0.2.4 |
| --- | ---: | ---: |
| Среднее время блока | 790 мкс | 312 мкс |
| P99 блока | 3 918 мкс | 867 мкс |
| Превышения бюджета 2 667 мкс | 122 из 1 536 | 0 из 1 536 |

Замеры выполнены обычным офлайн-хостом с синхронизацией потоков; результат
зависит от патча и нагрузки ОС. Прежний адаптер оставлен только как тестовый
эталон. На каждой платформе сравниваются все биты PCM: 210 сценариев, 1 720 320
стереосэмплов при 44,1/48/96 кГц, все модели фильтров, осцилляторы, 30 эффектов,
цепочки, сэмплы, макросы и разные размеры буферов.

```sh
output/plugin/build/rustias-au-benchmark /path/to/Rustias.component 512 parallel.json parallel
```

Тихий AU-бенчмарк сравнивает тембры внутри одного экземпляра с двумя/четырьмя
экземплярами, включая фильтры RADIAS и M/Poly. На Apple M5 Max, 48 кГц, буфере
32 сэмпла и восьми удерживаемых голосах на экземпляр с закрытыми редакторами:

| Нагрузка | P99 блока, 0.2.2 | P99 блока, 0.2.3 |
| --- | ---: | ---: |
| Два экземпляра RADIAS | 329 мкс | 131 мкс |
| Четыре экземпляра RADIAS | 690 мкс | 280 мкс |
| Четыре экземпляра M/Poly | 986 мкс | 393 мкс |

P99 в этих случаях снизился примерно на 60%. Средняя стоимость блока снизилась
примерно на 14–25%, а молчащего экземпляра — с 21 до 9 мкс. Бюджет блока — 667 мкс.
Замеры выполнены обычным офлайн-хостом; результат зависит от патча, планировщика
DAW и нагрузки машины. Каждую версию запускайте отдельным процессом:

```sh
cmake --build output/plugin/build --target rustias-au-benchmark
output/plugin/build/rustias-au-benchmark /path/to/Rustias.component 1024 result.json
```

`plugin/engine` собирает статическую библиотеку Rust, которая линкуется в
нативный плагин. Она использует `crates/radias-web` и общие `radias-synth-*`;
копии DSP нет. Скрипт `scripts/build-plugin-engine.py` включает отдельный
компиляторный cfg `rustias_plugin` в изолированной сборке Cargo. Обычная нативная
сборка, в том числе `--all-features`, сохраняет исходные эталонные размеры.
Каждый экземпляр плагина владеет своим движком и поддерживает смену потока DAW.
Расширенные пулы голосов выделяются в куче. Инициализация и загрузка полной
программы идут в подготовительном Rust-потоке со стеком 8 МиБ; рендер вызывает
нативный движок напрямую в потоке DAW.

`crates/radias-web/src/native/modulation.rs` хранит отдельные часы модуляции
для каждого экземпляра, интерполирует шаги, рассчитывает приоритет линий и
привязки макросов, меняет параметры и восстанавливает исходные значения.
Интерфейс только редактирует настройки и показывает позиции. Временные
смещения воспроизведения не попадают в сохранённую программу.
`plugin/src/RuntimeNative.cpp` передаёт управление, MIDI и аудиобуферы напрямую
в нативную библиотеку. Арифметика ресэмплинга сохранена. Звуковой поток не
заходит в JavaScriptCore или QuickJS; они используются только в тестовом эталоне.
Форматирование исходящих сообщений и массивов PCM для записи вынесено в отдельный
нативный поток; аудиопоток его не ждёт. Интерфейс открывается в WKWebView /
WebView2 / WebKitGTK (XEmbed). Wasmtime не используется. WASM-файл нужен для
локального разбора RDL и метаданных; звук плагина он не рендерит.

После установки интернет не нужен. Это первая сборка для разработки;
автоматические проверки не означают проверку во всех DAW или полное звуковое
соответствие железу. Лицензии зависимостей приведены в
`THIRD_PARTY_NOTICES.txt` и `licenses/` внутри плагина.

OSC 4 с пятью вариантами Wavefolder, новые модели фильтров и Poly motion входят в нативную сборку Rust. Playback у линии переключает общий режим Timbre и отдельную модуляцию каждого голоса. Курсоры, вероятности, переходы и модуляция огибающих исполняются на Rust. Poly motion следует темпу DAW, сохраняя BPM программы. Органы управления и доступные цели описаны в основном README.

В Linux GTK/WebKit и их цикл событий работают в отдельном helper-процессе. Неблокирующий IPC передаёт команды интерфейса и состояние; звук и модуляция остаются в Rust внутри плагина DAW.
