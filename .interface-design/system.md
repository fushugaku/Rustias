# Rustias browser instrument

The silver RADIAS faceplate, dark fluted knobs, blue LCD and red note pads are the signature. All 155 implemented native parameters share one full-width rack; only timbre selection changes its editing context. Signal flow: oscillators/mixer/filters/Drive, three envelopes and two LFOs, six virtual patches, then voice/pitch/amplifier/MIDI/tuning/drums. Four sequencer lanes and the keyboard sit below. No category tabs or decorative cards.

Tokens: plate #cbd0d5, inset #b7bec5, border #a4adb5, ink #262b30, secondary #46515b, toolbar #202327, LCD #c7dfeb with ink #334d61, red pads #d66169, focus #3e6380. Four-pixel spacing unit, three-pixel corners; only knobs/LEDs are circular. Arial/Helvetica for lettering, system monospace for values. Use rules to divide modules, recessed LCD shadows and fluted physical dials.

Desktop: a 24-column rack with fixed module spans. At ≥1400 px and ≤1000 px height use compact 36 px knobs, 56 px fields, nine voice columns and numeric custom-scale cells. The entire instrument fits 1440×900 with all native parameters, sequencer and keyboard. Larger screens have 48 px dials and more space. At ≤1399 px modules wrap; ≤800 px uses two columns; ≤520 px stacks complex sections, keeps touch targets ≥44 px and has four pad columns. Only the sequencer container scrolls sideways; the page must never overflow horizontally.

Choices use a shared blue LCD popover, with arrow/Home/End navigation, Escape and outside-click dismissal. On/Off controls are immediate LED switches. Drive has separate Off/Drive/WS, remembered WS Type, Depth and PreFilt1/PreAmp. Dependency states derive from current engine settings; PCM source controls, linked filters, Unison, tempo divisions and custom tuning show their actual availability. Source gain/Expression is explicit; automatic Unison gain bank is a readout.

Dial interaction: vertical drag, Shift for finer increments, wheel, arrows/Page/Home/End, direct numeric entry, double-click reset. Pads support multiple pointers; cancellation/focus loss releases notes. Full-screen uses the browser API.

Sequencer: four polyphonic tracks, each 1–128 steps, independent length, enable and Resolution (straight/triplet/dotted 1/32…1/1), shared Play/Stop/Reset and BPM. Each lane displays one block of sixteen steps with its own block picker. Editing a step opens a responsive chord keyboard with velocity/gate, clear/copy. Each note click auditions the entire resulting chord on that lane's timbre. Playback and audition use the native AudioWorklet frame clock. Editing does not change the original desktop sequencer.

When Drum mode is on, only the owning lane shows current sample names. Its editor replaces the octave keyboard with sixteen numbered red kit pads, four columns on desktop and two on mobile; all pads are 64 px high. Steps show the first sample name and the additional instrument count, with all names in their title and editor selection. Names follow Source assignments, Trigger and kit Transpose; shared triggers select and label every sounding instrument. Synth slots use Drum 01…16 and unmapped notes remain marked Unassigned. Changes to the kit refresh labels without changing stored sequence notes.

Storage: Save stores the complete engine, sequences and sample references in localStorage; the last session restores stopped. Program picker includes saved patches; JSON import/export retains older native and 16-step programs. Drum Source can select Synth, 224 bundled WAVs (64 CC0 808 and the complete 160-file Rob Roy 909 set) or custom uploads, with One-shot/Gate/Loop. Custom audio stays in IndexedDB. Sample, patch and step forms use aligned fields and buttons; mobile dialogs remain within the viewport.

Drum pads select the played instrument for editing and mark it with an LCD-colored border. The top context and all parameter values follow that instrument. Sample defaults use LPF24 at maximum cutoff; Morph 127 exposes Thru in the filter heading. PCM-only limitations (oscillators, common Mono/Unison/portamento/damper and One-shot envelope release) are inactive controls rather than apparently functional knobs.

Patch saving uses a split button: main Save updates the current saved patch, or names a new one when unsaved. The adjacent arrow opens Save current / Save copy… in the existing popover style, with 44 px touch targets. Copies use the existing name dialog, get an independent patch ID, retain complete engine/sequence/sample/RDL data and become current. Name proposals are unique and remain within 64 characters. Save menus suppress musical keyboard shortcuts while open.

PCM Amplifier controls are per instrument: Key track, Level offset, manual Source gain and MIDI volume/RX. Gain source remains common; Expression disables manual gain. CC7 reaches only instruments with RX enabled. Gain bank stays a computed readout, 0 for PCM. Step-editor header has aligned 44 px Previous / Next / Close buttons; navigation spans 1–128, switches the lane block at boundaries and disables arrows at the ends. Sequencer drum pads select their instrument for panel editing. Sample Source uses a searchable LCD picker; 808 kit and 909 kit sit together at the right of the Drum Kit heading.

The browser shares 48 voices across synthesis, kit PCM and direct sequence samples; monitor shows active / capacity. Drum Kit has a common Gain dial (-24…+24 dB, +12 dB initially) using the same fluted dial interaction. Source, Playback, Gain and Upload/Preview controls align at their labels and control tops.

Every step can add any bundled/custom sample from a searchable LCD picker inside the modal, independently of the sixteen kit slots and Drum mode. Sample chips expose sound editing and a separate remove action. Edit sound selects that timbre/source as the main panel context; Playback and Preview follow that sample. Each source has its own native DSP profile per timbre. The shared picker is reparented into an open dialog to remain interactive in the modal top layer.

Sequencer range editing: Select + tap endpoints on touch, drag on desktop or Shift-click to extend. Blue selection spans gaps and banks; Copy preserves the full range and Paste uses the chosen destination step. Ctrl/Cmd+C/V and Undo work outside text fields. A copied PCM kit trigger becomes a direct sample reference on another timbre so its sound survives the move. The step whose modal is open has a distinct LCD outline and aria-current; playback retains its red underline. Previous/Next moves that outline and the visible bank together.
