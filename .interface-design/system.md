# Rustias browser instrument

## Shared visual skin

Both Classic and New interface use the Sad Pet plugin family style. `web/theme.css`
owns the semantic palette and component skin; `styles.css` and `new-interface.css`
keep layout and responsive behavior. Do not add hardcoded colors to those layout
files. The shared controls, DSP, program formats and clock remain unchanged.

Keep playback distinct from selection. Four/eight-pixel spacing, six-pixel controls,
eight-pixel panel/dialog corners. Depth comes from surface changes and subtle
rules; shadows belong to popovers and the small dial faces.

Use the system sans stack (Inter when installed), small tracked section headings,
readable control labels and monospace numeric values. Dials have a smooth olive
face, pale pointer and a 270-degree lime value arc from the original --angle.
The teal modulation marker remains independent. Synth and FX dial labels sit below
the face, then their value; choices/switches retain labels above. Eight macros form
centered vertical groups with their assignment pencil and target summary. On phone
widths use four columns and 44px edit targets. The waveform logo identifies RUSTIAS
on desktop and mobile. All menus, inspectors, drums, recorder and Build use this
same palette and shared control tokens.

## New interface

`?interface=new` is a second presentation of the same controls, not a DSP fork. Classic/New interface navigation opens the other presentation in a separate browser tab. Keep the Classic layout below intact; all new selectors are scoped to `.new-interface`. `new-interface.js` reparents original controls before the circuit editor captures their parents. `sequence-workspace.js` observes the canonical sequencer API; its pure display helpers live in `sequence-view.js`. Playback clocks, program formats and audio processing are shared.

Desktop uses a compact two-row dark olive header, eight macros with target summaries, an internally scrolling dark synthesis rack, a 320px FX column and a resizable sequencer dock. Program/Save/Timbre remain adjacent; BPM/Play/Record share the transport row. Files and Controls use anchored popovers. Macros and Keyboard fold independently. Rack section shortcuts scroll only the rack. EG1–3 and LFO1–3 have thin vertical separators when adjacent and horizontal separators when stacked. Start each LFO group on a new grid row. Virtual Patch uses four equal modules per desktop row (>1100px), two at 801–1100px and one on phones. Each patch stacks full-width Source/Destination LCD fields above two equal Intensity/Offset dials. Master has a stronger separator; empty FX slots stay compact and active parameters can fold independently.

Sequence views: Steps keeps all lanes; Piano roll and Samples edit the selected lane. A 128-step overview retains muted events and events outside shortened loops and selects the selected timbre's visible block. Hide the redundant per-lane block dropdowns in New interface; Classic keeps them. Grid rows show exact MIDI pitches or kit/direct sample identities, with velocity opacity and gate length; lime selection/editor outlines stay distinct from the red playback underline. Select + endpoints works on touch; Shift-click selects a range on desktop. Step properties use the original dialog nonmodally as a right inspector, so synthesizer controls remain usable. An open Mod Sequence replaces the roll area with its own scrolling controls. The separator supports pointer drag and keyboard Up/Down/Home/End. Layout preferences are separate from programs.

At ≤800px use a sticky three-row header, a timbre dropdown plus Add, and aligned 44px transport controls. Keep page width within the viewport; grid scrolling stays internal. Macros default folded with a separate phone preference, effects can fold, and the inspector stacks below the pattern and scrolls into view below the header. Sound section shortcuts must not scroll the whole page. Build owns a flex viewport with Fit, selected cable emphasis and a minimap inside the canvas workspace, never overlapping its toolbar. Preserve readable native units, dependency states and original dial interaction throughout.

## Classic interface

The dark olive faceplate, smooth value-arc knobs, inset choices and lime active pads are the signature. All 155 implemented native parameters plus twenty-four controls for browser Patch 7/8, LFO 3 and OSC 3 share one full-width rack; only timbre selection changes its editing context. Signal flow: three oscillators/mixer/filters/Drive, three envelopes and three LFOs, eight virtual patches, then voice/pitch/amplifier/MIDI/tuning/drums. Up to eight sequencer lanes and the keyboard sit below. No category tabs or decorative cards.

Use the shared visual skin above. Keep the Classic rack density and module rules; only knobs and LEDs are circular.

Desktop: a 28-column oscillator row and 24-column voice row with fixed module spans. At ≥1400 px and ≤1000 px height use compact 36 px knobs, 56 px fields, nine voice columns and numeric custom-scale cells. Added timbres, macros and active FX extend the scrollable content; keep the header and performance footer available. Larger screens have 48 px dials and more space. At ≤1399 px modules wrap; ≤800 px uses two columns; ≤520 px stacks complex sections, keeps touch targets ≥44 px and has four pad columns. Only the sequencer container scrolls sideways; the page must never overflow horizontally.

Choices use a shared inset choice popover, with arrow/Home/End navigation, Escape and outside-click dismissal. On/Off controls are immediate LED switches. Drive has separate Off/Drive/WS, remembered WS Type, Depth and PreFilt1/PreAmp. Dependency states derive from current engine settings; PCM source controls, linked filters, Unison, tempo divisions and custom tuning show their actual availability. Source gain/Expression is explicit; automatic Unison gain bank is a readout.

Dial interaction: vertical drag, Shift for finer increments, wheel, arrows/Page/Home/End, direct numeric entry, double-click reset. Pads support multiple pointers; cancellation/focus loss releases notes. Full-screen uses the browser API.

Sequencer: one polyphonic track per timbre, up to eight, each 1–128 steps, independent length, enable and Resolution (straight/triplet/dotted 1/32…1/1), shared Play/Stop/Reset and BPM. Each lane displays one block of sixteen steps with its own block picker. Editing a step opens a responsive chord keyboard with velocity/gate, clear/copy. Each note click auditions the entire resulting chord on that lane's timbre. Playback and audition use the native AudioWorklet frame clock. Editing does not change the original desktop sequencer.

When Drum mode is on, only the owning lane shows current sample names. Its editor replaces the octave keyboard with sixteen numbered kit pads, four columns on desktop and two on mobile; all pads are 64 px high. Steps show the first sample name and the additional instrument count, with all names in their title and editor selection. Names follow Source assignments, Trigger and kit Transpose; shared triggers select and label every sounding instrument. Synth slots use Drum 01…16 and unmapped notes remain marked Unassigned. Changes to the kit refresh labels without changing stored sequence notes.

Storage: Save stores the complete engine, sequences and sample references in localStorage; the last session restores stopped. Program picker includes saved patches; JSON import/export retains older native and 16-step programs. Drum Source can select Synth, 224 bundled WAVs (64 CC0 808 and the complete 160-file Rob Roy 909 set) or custom uploads, with One-shot/Gate/Loop. Custom audio stays in IndexedDB. Sample, patch and step forms use aligned fields and buttons; mobile dialogs remain within the viewport.

Drum pads select the played instrument for editing and mark it with an LCD-colored border. The top context and all parameter values follow that instrument. Sample defaults use LPF24 at maximum cutoff; Morph 127 exposes Thru in the filter heading. PCM-only limitations (oscillators, common Mono/Unison/portamento/damper and One-shot envelope release) are inactive controls rather than apparently functional knobs.

Program and Timbre sound use separate adjacent LCD pickers. Program selects the entire program with up to eight timbres and their sequencer lanes; Timbre sound loads only the selected slot’s sound, source profiles and module graph/layout, preserving its pattern and MIDI/key routing. Program names stay selected after edits; an asterisk marks changes. Each program embeds timbre values and names independently of the sound library.

The split Save button updates the current program or opens its name dialog. The arrow offers Save program / Save program copy…, then Save timbre / Save timbre copy… / Export timbre, with 44 px targets and keyboard navigation. Copies get independent IDs. Program JSON retains all timbres, sequences, sample settings, circuits and output volume; individual timbre JSON imports into the sound library and selected slot. Both libraries and the session persist locally, playback restores stopped. At mobile widths the two equal LCD pickers share a row; file actions occupy the following row.

PCM Amplifier controls are per instrument: Key track, Level offset, manual Source gain and MIDI volume/RX. Gain source remains common; Expression disables manual gain. CC7 reaches only instruments with RX enabled. Gain bank stays a computed readout, 0 for PCM. Step-editor header has aligned 44 px Previous / Next / Close buttons; navigation spans 1–128, switches the lane block at boundaries and disables arrows at the ends. Sequencer drum pads select their instrument for panel editing. Sample Source uses a searchable LCD picker; 808 kit and 909 kit sit together at the right of the Drum Kit heading.

The browser shares 128 voices across synthesis, kit PCM and direct sequence samples; monitor shows active / capacity. Drum Kit has a common Gain dial (-24…+24 dB, +12 dB initially) using the same smooth dial interaction. Source, Playback, Gain and Upload/Preview controls align at their labels and control tops.

Every step can add any bundled/custom sample from a searchable LCD picker inside the modal, independently of the sixteen kit slots and Drum mode. Sample chips expose sound editing and a separate remove action. Edit sound selects that timbre/source as the main panel context; Playback and Preview follow that sample. Each source has its own native DSP profile per timbre. The shared picker is reparented into an open dialog to remain interactive in the modal top layer.

Sequencer range editing: Select + tap endpoints on touch, drag on desktop or Shift-click to extend. Lime selection spans gaps and banks; Copy preserves the full range and Paste uses the chosen destination step. Ctrl/Cmd+C/V and Undo work outside text fields. A copied PCM kit trigger becomes a direct sample reference on another timbre so its sound survives the move. The step whose modal is open has a distinct LCD outline and aria-current; playback retains its red underline. Previous/Next moves that outline and the visible bank together.

Build opens a separate dark patch canvas per timbre. Existing native sections are reparented into movable modules and returned to the rack without losing their control handlers. Headings drag or move by keyboard; audio ports/cables are lime, CV teal. Output → input clicks connect; a connected input or cable selects it for Disconnect/Delete. Additional OSC/filter/Drive/VCA/mixer/LFO/envelope modules have the same knobs and LCD choices. Canvas zoom and its own two-axis scrolling keep the page within mobile width. Ports remain 44 px at 100%. Routing On/Off explicitly switches the DSP graph; movement only changes layout. Reset modules, Undo and Redo are reversible. All timbre layouts, new controls and cables persist in patches and the session.

Add module includes an independent full OSC 1 with Waveform/Cross/Unison/VPM, six waveforms, CTRL1/2, semitone/cents and level. Noise/Formant force Waveform and disable Mode. Ports: audio mod; CV ctrl1/ctrl2/pitch/lfo, arranged in two input columns. Added modules are placed using their measured dimensions to avoid overlap. All synthesis nodes except Output have × in their draggable heading; removing a builtin also removes its cables, enables routing, and makes that type available for re-addition. Undo/Redo and program/timbre storage preserve removals. Original controls return intact to the fixed rack on leaving Build.

Switch uses the same dark module and LCD Route A/B choice. Audio outputs A/B form a vertical column opposite in/select inputs; ports and cables retain their individual output identity. Optional select CV overrides Route. The UI never moves modules when Drive Position rewires a serial path. Drag handlers belong to one primary pointer, tolerate canvas scrolling/zoom and are disposed before reparenting; release, lost capture, blur and cancellation end a gesture. Parameter buttons never start module dragging.

Five dark FX panels follow either rack or Build: Insert 1/2, Timbre FX 3/4, then shared Master. FX 3/4 have the full Master catalog and each timbre's audio/controller context. Each panel has an aligned heading/power and searchable LCD type selector, using the generated Rust catalog. Desktop uses five equal panels and four property columns; medium widths wrap into three columns. Mobile stacks panels with 44px value LCDs and 112px parameter rows. Value LCD pickers show native note fractions, time/frequency/dB units and enums from the Rust display tables. TempoSync shows only the relevant free/sync time or LFO field. Wide Rotary/Talking insert types dim and disable Insert 2 without affecting FX 3/4. Slot identities remain stable while switching timbres and loading older programs. Programs retain all 33 slots; individual sounds carry four effects. Macro assignment and Mod Sequencer choices cover the new FX controls.

Recording controls sit with the keyboard: dark Record button with red active state, fixed-width inset elapsed-time display, searchable folder picker, Recordings disclosure. Keep the active destination pinned during capture. The nonmodal library is a separate section before the sticky performance footer, so a long folder list never pushes recording controls underneath the sticky header. Folders use collapsible dark rows, editable names, take duration/date and aligned Listen/WAV/MP3/Move/delete actions. Prepared file links stay available after encoding. Mobile uses 44px controls, a two-row recorder strip and aligned take actions (two rows on narrow screens). Names save on input debounce, blur or Enter.

Timbre tabs start at four; the adjacent + adds a sound and sequencer lane up to eight. At mobile widths use four equal columns and a second row. New timbres receive independent channel, four timbre FX and module layout; unused slots stay hidden. Eight virtual-patch modules span the same rack row on desktop and wrap on small screens.

Program macros use eight smooth dials with numeric percentage and an assignment count/pencil button underneath. Mobile uses four columns and 44px input/edit targets. Right click, Shift+F10 or touch hold opens Assign to macro; dragging cancels touch hold. The pencil opens the name and target list; each row has a full-width target label, signed influence slider (-100…+100%), fixed-width percentage and 44px remove button. Up to twelve bindings per macro. Knob positions, shared base values, names and signed amounts persist with programs, copies, JSON and sessions.

Mod Sequencer: a 44px disclosure beside each T1–T8 lane opens a dark subpanel and selects its timbre. + Mod adds up to six rows; the disclosure uses LCD color when rows exist. Each row has On, searchable Parameter (including eight program Macros), bipolar Intensity, independent Steps/Bars/Resolution, Step/Slide, direction, Loop/OneShot, optional sixteen-step block picker and remove. Sixteen smooth step dials use signed offsets and centered zero; active playback has the same red underline as notes. Desktop shows inactive knobs dimmed; mobile hides inactive steps, uses up to four columns and equal-width 44px LCD fields. Each main note row owns its horizontal scrolling, so expanded modulation panels fit the viewport.

Live modulation uses a second teal marker on synth and Macro dials; the primary dial and numeric input retain the saved base value. Stop/Pause clear these markers immediately. Timing and Macro composition stay in the AudioWorklet; UI messages only update markers and step highlights. Modulation is stored with programs/copies/session/JSON and with individual timbre sounds; target ownership remaps on timbre loading.

RDL sequencing: the note lane's ⋯ opens aligned settings on the dark plate (six desktop columns, two mobile columns). Imported Pattern, RunMode, Key trigger/Latch/KeySync/Transpose, signed Swing/Gate offset and note scan range use matching inset choices; mobile fields are 44px high. Unassigned RDL Seq 1/2 remain selectable. The step modal adds Trigger, TIE/% and Fixed/Key velocity choices without discarding muted chords. Muted triggers dim their note cells. Imported Mod rows retain their signed dials and add an aligned KeySync selector; Voice uses the shared timbre clock and its limitation is included in the RDL report.

LFO 3 uses the shared Rust LFO 1 waveform/clock algorithm behind `web-expanded` + wasm32; desktop remains at two. Append its eight stored parameter IDs at 163–170 and source ID 16 / rate destination 42; keep all native/old browser indexes stable. Add a removable builtin LFO 3 CV node at ID 63 in new graphs, preserving the original 0–15 IDs and existing user modules. Older graphs can add LFO 3 through Add module. Program/timbre/sample storage, macro gestures and Mod Sequencer choices use the extended schema.

OSC 3 replaces Noise at builtin node 2, preserving old IDs/cables. It has OSC 1's six waveforms/four modes and CTRL1/2, OSC 2's Semi/Fine, plus independent Ring/Sync and Source (OSC 1, OSC 2 before Ring, current OSC 1→2 result). Its four LCDs occupy two equal columns; the four dials share the following row. Keep OSC 1/2/3 bottom rules aligned on desktop, and OSC 3 full-width on phones. Source references use native audio/phase taps; the original pair is unchanged. Store IDs 171–178, Virtual Patch destinations 43–51 and existing Level 5. Noise/Formant disable only synthesis Mode. CV/audio ports and macro gestures follow independent OSC 1. Defaults retain Noise with Ring/Sync off, native desktop retains its original Noise generator.
