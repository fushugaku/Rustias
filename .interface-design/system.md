# Rustias browser instrument

The silver RADIAS faceplate, dark fluted knobs, blue LCD and red note pads are the signature. All 155 implemented native parameters share one full-width rack; only timbre selection changes its editing context. Signal flow: oscillators/mixer/filters/Drive, three envelopes and two LFOs, six virtual patches, then voice/pitch/amplifier/MIDI/tuning/drums. Four sequencer lanes and the keyboard sit below. No category tabs or decorative cards.

Tokens: plate #cbd0d5, inset #b7bec5, border #a4adb5, ink #262b30, secondary #46515b, toolbar #202327, LCD #c7dfeb with ink #334d61, red pads #d66169, focus #3e6380. Four-pixel spacing unit, three-pixel corners; only knobs/LEDs are circular. Arial/Helvetica for lettering, system monospace for values. Use rules to divide modules, recessed LCD shadows and fluted physical dials.

Desktop: a 24-column rack with fixed module spans. At ≥1400 px and ≤1000 px height use compact 36 px knobs, 56 px fields, nine voice columns and numeric custom-scale cells. The entire instrument fits 1440×900 with all native parameters, sequencer and keyboard. Larger screens have 48 px dials and more space. At ≤1399 px modules wrap; ≤800 px uses two columns; ≤520 px stacks complex sections, keeps touch targets ≥44 px and has four pad columns. Only the sequencer container scrolls sideways; the page must never overflow horizontally.

Choices use a shared blue LCD popover, with arrow/Home/End navigation, Escape and outside-click dismissal. On/Off controls are immediate LED switches. Drive has separate Off/Drive/WS, remembered WS Type, Depth and PreFilt1/PreAmp. Dependency states derive from current engine settings; PCM source controls, linked filters, Unison, tempo divisions and custom tuning show their actual availability. Source gain/Expression is explicit; automatic Unison gain bank is a readout.

Dial interaction: vertical drag, Shift for finer increments, wheel, arrows/Page/Home/End, direct numeric entry, double-click reset. Pads support multiple pointers; cancellation/focus loss releases notes. Full-screen uses the browser API.

Sequencer: four polyphonic tracks, each 1–128 steps, independent length, enable and Resolution (straight/triplet/dotted 1/32…1/1), shared Play/Stop/Reset and BPM. Each lane displays one block of sixteen steps with its own block picker. Editing a step opens a responsive chord keyboard with velocity/gate, clear/copy. Each note click auditions the entire resulting chord on that lane's timbre. Playback and audition use the native AudioWorklet frame clock. Editing does not change the original desktop sequencer.

Storage: Save stores the complete engine, sequences and sample references in localStorage; the last session restores stopped. Program picker includes saved patches; JSON import/export retains older native and 16-step programs. Drum Source can select Synth, 64 bundled CC0 WAVs or custom uploads, with One-shot/Gate/Loop. Custom audio stays in IndexedDB. Sample, patch and step forms use aligned fields and buttons; mobile dialogs remain within the viewport.

Patch saving uses a split button: main Save updates the current saved patch, or names a new one when unsaved. The adjacent arrow opens Save current / Save copy… in the existing popover style, with 44 px touch targets. Copies use the existing name dialog, get an independent patch ID, retain complete engine/sequence/sample/RDL data and become current. Name proposals are unique and remain within 64 characters. Save menus suppress musical keyboard shortcuts while open.
