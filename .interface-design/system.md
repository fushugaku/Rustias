# Rustias browser instrument

The silver RADIAS faceplate, dark fluted knobs, blue LCD and red note pads are the signature. All 155 implemented native parameters plus eight controls for browser Patch 7/8 share one full-width rack; only timbre selection changes its editing context. Signal flow: oscillators/mixer/filters/Drive, three envelopes and two LFOs, eight virtual patches, then voice/pitch/amplifier/MIDI/tuning/drums. Up to eight sequencer lanes and the keyboard sit below. No category tabs or decorative cards.

Tokens: plate #cbd0d5, inset #b7bec5, border #a4adb5, ink #262b30, secondary #46515b, toolbar #202327, LCD #c7dfeb with ink #334d61, red pads #d66169, focus #3e6380. Four-pixel spacing unit, three-pixel corners; only knobs/LEDs are circular. Arial/Helvetica for lettering, system monospace for values. Use rules to divide modules, recessed LCD shadows and fluted physical dials.

Desktop: a 24-column rack with fixed module spans. At ≥1400 px and ≤1000 px height use compact 36 px knobs, 56 px fields, nine voice columns and numeric custom-scale cells. Added timbres, macros and active FX extend the scrollable content; keep the header and performance footer available. Larger screens have 48 px dials and more space. At ≤1399 px modules wrap; ≤800 px uses two columns; ≤520 px stacks complex sections, keeps touch targets ≥44 px and has four pad columns. Only the sequencer container scrolls sideways; the page must never overflow horizontally.

Choices use a shared blue LCD popover, with arrow/Home/End navigation, Escape and outside-click dismissal. On/Off controls are immediate LED switches. Drive has separate Off/Drive/WS, remembered WS Type, Depth and PreFilt1/PreAmp. Dependency states derive from current engine settings; PCM source controls, linked filters, Unison, tempo divisions and custom tuning show their actual availability. Source gain/Expression is explicit; automatic Unison gain bank is a readout.

Dial interaction: vertical drag, Shift for finer increments, wheel, arrows/Page/Home/End, direct numeric entry, double-click reset. Pads support multiple pointers; cancellation/focus loss releases notes. Full-screen uses the browser API.

Sequencer: one polyphonic track per timbre, up to eight, each 1–128 steps, independent length, enable and Resolution (straight/triplet/dotted 1/32…1/1), shared Play/Stop/Reset and BPM. Each lane displays one block of sixteen steps with its own block picker. Editing a step opens a responsive chord keyboard with velocity/gate, clear/copy. Each note click auditions the entire resulting chord on that lane's timbre. Playback and audition use the native AudioWorklet frame clock. Editing does not change the original desktop sequencer.

When Drum mode is on, only the owning lane shows current sample names. Its editor replaces the octave keyboard with sixteen numbered red kit pads, four columns on desktop and two on mobile; all pads are 64 px high. Steps show the first sample name and the additional instrument count, with all names in their title and editor selection. Names follow Source assignments, Trigger and kit Transpose; shared triggers select and label every sounding instrument. Synth slots use Drum 01…16 and unmapped notes remain marked Unassigned. Changes to the kit refresh labels without changing stored sequence notes.

Storage: Save stores the complete engine, sequences and sample references in localStorage; the last session restores stopped. Program picker includes saved patches; JSON import/export retains older native and 16-step programs. Drum Source can select Synth, 224 bundled WAVs (64 CC0 808 and the complete 160-file Rob Roy 909 set) or custom uploads, with One-shot/Gate/Loop. Custom audio stays in IndexedDB. Sample, patch and step forms use aligned fields and buttons; mobile dialogs remain within the viewport.

Drum pads select the played instrument for editing and mark it with an LCD-colored border. The top context and all parameter values follow that instrument. Sample defaults use LPF24 at maximum cutoff; Morph 127 exposes Thru in the filter heading. PCM-only limitations (oscillators, common Mono/Unison/portamento/damper and One-shot envelope release) are inactive controls rather than apparently functional knobs.

Program and Timbre sound use separate adjacent LCD pickers. Program selects the entire program with up to eight timbres and their sequencer lanes; Timbre sound loads only the selected slot’s sound, source profiles and module graph/layout, preserving its pattern and MIDI/key routing. Program names stay selected after edits; an asterisk marks changes. Each program embeds timbre values and names independently of the sound library.

The split Save button updates the current program or opens its name dialog. The arrow offers Save program / Save program copy…, then Save timbre / Save timbre copy… / Export timbre, with 44 px targets and keyboard navigation. Copies get independent IDs. Program JSON retains all timbres, sequences, sample settings, circuits and output volume; individual timbre JSON imports into the sound library and selected slot. Both libraries and the session persist locally, playback restores stopped. At mobile widths the two equal LCD pickers share a row; file actions occupy the following row.

PCM Amplifier controls are per instrument: Key track, Level offset, manual Source gain and MIDI volume/RX. Gain source remains common; Expression disables manual gain. CC7 reaches only instruments with RX enabled. Gain bank stays a computed readout, 0 for PCM. Step-editor header has aligned 44 px Previous / Next / Close buttons; navigation spans 1–128, switches the lane block at boundaries and disables arrows at the ends. Sequencer drum pads select their instrument for panel editing. Sample Source uses a searchable LCD picker; 808 kit and 909 kit sit together at the right of the Drum Kit heading.

The browser shares 128 voices across synthesis, kit PCM and direct sequence samples; monitor shows active / capacity. Drum Kit has a common Gain dial (-24…+24 dB, +12 dB initially) using the same fluted dial interaction. Source, Playback, Gain and Upload/Preview controls align at their labels and control tops.

Every step can add any bundled/custom sample from a searchable LCD picker inside the modal, independently of the sixteen kit slots and Drum mode. Sample chips expose sound editing and a separate remove action. Edit sound selects that timbre/source as the main panel context; Playback and Preview follow that sample. Each source has its own native DSP profile per timbre. The shared picker is reparented into an open dialog to remain interactive in the modal top layer.

Sequencer range editing: Select + tap endpoints on touch, drag on desktop or Shift-click to extend. Blue selection spans gaps and banks; Copy preserves the full range and Paste uses the chosen destination step. Ctrl/Cmd+C/V and Undo work outside text fields. A copied PCM kit trigger becomes a direct sample reference on another timbre so its sound survives the move. The step whose modal is open has a distinct LCD outline and aria-current; playback retains its red underline. Previous/Next moves that outline and the visible bank together.

Build opens a separate silver patch canvas per timbre. Existing native sections are reparented into movable modules and returned to the rack without losing their control handlers. Headings drag or move by keyboard; audio ports/cables are blue, CV red. Output → input clicks connect; a connected input or cable selects it for Disconnect/Delete. Additional OSC/filter/Drive/VCA/mixer/LFO/envelope modules have the same knobs and LCD choices. Canvas zoom and its own two-axis scrolling keep the page within mobile width. Ports remain 44 px at 100%. Routing On/Off explicitly switches the DSP graph; movement only changes layout. Reset modules, Undo and Redo are reversible. All timbre layouts, new controls and cables persist in patches and the session.

Add module includes an independent full OSC 1 with Waveform/Cross/Unison/VPM, six waveforms, CTRL1/2, semitone/cents and level. Noise/Formant force Waveform and disable Mode. Ports: audio mod; CV ctrl1/ctrl2/pitch/lfo, arranged in two input columns. Added modules are placed using their measured dimensions to avoid overlap. All synthesis nodes except Output have × in their draggable heading; removing a builtin also removes its cables, enables routing, and makes that type available for re-addition. Undo/Redo and program/timbre storage preserve removals. Original controls return intact to the fixed rack on leaving Build.

Switch uses the same silver module and LCD Route A/B choice. Audio outputs A/B form a vertical column opposite in/select inputs; ports and cables retain their individual output identity. Optional select CV overrides Route. The UI never moves modules when Drive Position rewires a serial path. Drag handlers belong to one primary pointer, tolerate canvas scrolling/zoom and are disposed before reparenting; release, lost capture, blur and cancellation end a gesture. Parameter buttons never start module dragging.

Three silver FX panels follow either rack or Build: two inserts for the selected timbre, then shared Master. Each has an aligned heading/power and searchable LCD type selector, using the generated Rust catalog. Native property knobs form five desktop columns (four at medium widths); mobile stacks the three panels and keeps four columns, 44px value LCDs and 112px parameter rows. Value LCD pickers show native note fractions, time/frequency/dB units and enums from the Rust display tables. TempoSync shows only the relevant free/sync time or LFO field. Wide Rotary/Talking insert types dim and disable Insert 2 without deleting it. Control handlers retain their actual slot index while switching timbres. FX are stereo bus processors after the voice graph; program storage includes all seventeen slots, timbre storage includes two inserts.

Recording controls sit with the keyboard: silver Record button with red active state, fixed-width blue elapsed-time LCD, searchable folder picker, Recordings disclosure. Keep the active destination pinned during capture. The nonmodal library is a separate section before the sticky performance footer, so a long folder list never pushes recording controls underneath the sticky header. Folders use collapsible silver rows, editable names, take duration/date and aligned Listen/WAV/MP3/Move/delete actions. Prepared file links stay available after encoding. Mobile uses 44px controls, a two-row recorder strip and aligned take actions (two rows on narrow screens). Names save on input debounce, blur or Enter.

Timbre tabs start at four; the adjacent + adds a sound and sequencer lane up to eight. At mobile widths use four equal columns and a second row. New timbres receive independent channel, two FX inserts and module layout; unused slots stay hidden. Eight virtual-patch modules span the same rack row on desktop and wrap on small screens.

Program macros use eight fluted dials with numeric percentage and an assignment count/pencil button underneath. Mobile uses four columns and 44px input/edit targets. Right click, Shift+F10 or touch hold opens Assign to macro; dragging cancels touch hold. The pencil opens the name and target list; each row has a full-width target label, signed influence slider (-100…+100%), fixed-width percentage and 44px remove button. Up to twelve bindings per macro. Knob positions, shared base values, names and signed amounts persist with programs, copies, JSON and sessions.

Mod Sequencer: a 44px disclosure beside each T1–T8 lane opens a silver subpanel and selects its timbre. + Mod adds up to six rows; the disclosure uses LCD color when rows exist. Each row has On, searchable Parameter (including eight program Macros), bipolar Intensity, independent Steps/Bars/Resolution, Step/Slide, direction, Loop/OneShot, optional sixteen-step block picker and remove. Sixteen fluted step dials use signed offsets and centered zero; active playback has the same red underline as notes. Desktop shows inactive knobs dimmed; mobile hides inactive steps, uses up to four columns and equal-width 44px LCD fields. Each main note row owns its horizontal scrolling, so expanded modulation panels fit the viewport.

Live modulation uses a second blue marker on synth and Macro dials; the primary dial and numeric input retain the saved base value. Stop/Pause clear these markers immediately. Timing and Macro composition stay in the AudioWorklet; UI messages only update markers and step highlights. Modulation is stored with programs/copies/session/JSON and with individual timbre sounds; target ownership remaps on timbre loading.
